# Shimil Shaji portfolio

Plain HTML, CSS and JS. No build step.

## Add your Reels
Put 6 thumbnails (9:16, JPG) in `assets/reels/` named `reel-1.jpg` to `reel-6.jpg`. Until then, grey placeholder tiles show.
To link each tile to its own Reel, replace the `href` of each `<a class="reel">` in `index.html`.

## Publish for free
Netlify Drop (app.netlify.com/drop): drag this whole folder onto the page. Or use GitHub Pages / Vercel.
After publishing, change `og:image` in `index.html` to the full URL of `assets/photo-hero.jpg`, then update the website link in your CV.

## CV
`assets/Shimil-Shaji-CV.pdf` is the file behind the Download CV buttons. Replace it with the same name to update.
