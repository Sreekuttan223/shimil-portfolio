# Shimil Shaji — Portfolio

This is the complete static portfolio website, built with plain HTML, CSS and JavaScript. It includes the photos, company logos, certificate image, CV, Instagram Reel thumbnails, responsive styling and page animations.

## No build or backend required

There is no build step, package installation, server-side code or environment variables. GitHub Pages can host the site directly.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Unzip this package and upload the **contents** of this folder to the repository root. Make sure `index.html` is at the root beside `styles.css`, `script.js` and the `assets` folder.
3. Commit the files to the `main` branch.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. GitHub will show the published website URL on the Pages settings screen after deployment finishes.

All website images and other local files use relative paths, so keep the `assets` folder and its subfolders in place. Instagram and LinkedIn links open their respective external pages. The CV download uses `assets/Shimil-Shaji-CV.pdf`.

## Update the site

- Replace a photo or logo with the same filename and path to keep the existing page references working.
- Reel cards 1–5 link to individual Instagram Reels. Card 6 links to the Instagram profile.
- Edit `index.html` for text and links, `styles.css` for visual styling and animations, and `script.js` for interactive behavior.
